EXAMPLE 1 · PYTHON

Names, values and a small bill

A variable gives a name to a value. Keeping quantities separate makes a calculation easier to read and change.

Complete code

price = 12
quantity = 3
total = price * quantity
print(f"Total: {total}")

Expected output

Total: 36

Read it step by step

  1. price and quantity store integers. Their names explain what the numbers mean.
  2. The * operator multiplies; the result is stored in total.
  3. The f-string inserts total inside the displayed text. print ends the line with a newline.
  4. Change quantity to 4 and reason that the output becomes Total: 48 before running it.

Remember: A variable is a name for a value, not a promise that the value can never change.

EXAMPLE 2 · PYTHON

Convert text before arithmetic

User input and file fields often arrive as strings. Convert them when the operation requires numbers.

Complete code

text = "15"
number = int(text)
print(text + "5")
print(number + 5)

Expected output

155
20

Read it step by step

  1. The quotation marks create text. Adding two strings joins their characters.
  2. int(text) parses an integer from the text; it can raise ValueError for invalid input.
  3. The first print joins "15" and "5". The second adds the numbers 15 and 5.
  4. If text were "fifteen", conversion would fail rather than guess a number.

Remember: The same + symbol has different behavior for strings and numbers.

EXAMPLE 3 · PYTHON

Filter a list with a loop

A loop repeats a small action for each item. An if statement chooses when that action should happen.

Complete code

values = [2, 7, 4, 9]
kept = []
for value in values:
    if value >= 5:
        kept.append(value)
print(kept)

Expected output

[7, 9]

Read it step by step

  1. Start with an empty result list. Each iteration gives value the next number.
  2. The >= test is true only for 7 and 9.
  3. append adds one accepted item to the end. Input order is preserved.
  4. A list comprehension [v for v in values if v >= 5] expresses the same selection more compactly.

Remember: Use the longer loop until the condition and update are clear.

EXAMPLE 4 · PYTHON

Write a function with a clear return value

A function packages a reusable rule. Returning an answer is different from displaying it.

Complete code

def bill(count, price=10):
    return count * price

first = bill(3)
second = bill(2, price=7)
print(first)
print(second)

Expected output

30
14

Read it step by step

  1. def defines a function; its body runs when the function is called.
  2. price=10 supplies a default only when no price argument is provided.
  3. return sends a value back to the caller. Here the caller stores it in a name.
  4. The two print calls display the results; the function itself does not print.

Remember: Separate calculation from display so a function can be reused in other contexts.

EXAMPLE 5 · PYTHON

Count items with a dictionary

A dictionary associates keys with values. It can keep a running count for each label.

Complete code

labels = ["red", "blue", "red", "green", "blue", "red"]
counts = {}
for label in labels:
    counts[label] = counts.get(label, 0) + 1
for label in sorted(counts):
    print(label, counts[label])

Expected output

blue 2
green 1
red 3

Read it step by step

  1. The label is the key and its count is the value.
  2. get(label, 0) returns an existing count or zero for a new label.
  3. Adding one and assigning it updates the count for that occurrence.
  4. sorted(counts) sorts keys for predictable display; it does not change the stored counts.

Remember: Dictionaries are useful when you need a value associated with each distinct key.

EXAMPLE 6 · PYTHON

Understand a list copy

Two names can refer to the same mutable list. A shallow copy creates a new outer list, but does not recursively copy nested objects.

Complete code

original = [1, 2]
alias = original
separate = original.copy()
alias.append(3)
print(original)
print(separate)

Expected output

[1, 2, 3]
[1, 2]

Read it step by step

  1. alias = original does not create a list. Both names point to the same object.
  2. copy creates a new outer list containing the same entries.
  3. Appending through alias therefore changes original, but not separate.
  4. For nested lists, a shallow copy still shares the nested objects; consider the intended ownership before copying.

Remember: Assignment and copying are different operations.

EXAMPLE 7 · PYTHON

Handle a specific conversion failure

An exception lets code report that an operation could not finish normally. Catch the failure you can actually handle.

Complete code

items = ["3", "bad", "5"]
total = 0
for item in items:
    try:
        total += int(item)
    except ValueError:
        print(f"Skipped: {item}")
print(f"Total: {total}")

Expected output

Skipped: bad
Total: 8

Read it step by step

  1. int succeeds for "3" and "5", adding them to total.
  2. It raises ValueError for "bad". Control moves to the matching except block.
  3. The message records the skipped input rather than silently losing it.
  4. The loop continues, but in some applications rejecting the entire input would be more appropriate.

Remember: Choose error handling according to the task instead of catching every exception blindly.

EXAMPLE 8 · PYTHON

Generate values one at a time

A generator yields a sequence without constructing the entire result list in advance.

Complete code

def squares(limit):
    for number in range(limit):
        yield number * number

stream = squares(4)
print(next(stream))
print(list(stream))

Expected output

0
[1, 4, 9]

Read it step by step

  1. Calling squares creates a generator; it does not immediately run every loop iteration.
  2. next requests the first yielded value, 0.
  3. list consumes the remaining values, not the already-consumed first value.
  4. Once exhausted, a generator does not restart; call squares again to create a new one.

Remember: A generator is a stateful stream, so consuming it changes what remains.
