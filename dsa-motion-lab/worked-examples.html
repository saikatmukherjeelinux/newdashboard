EXAMPLE 1 · PYTHON

Linear search: inspect one item at a time

Linear search works without sorted input. It returns the first matching position, or a clearly specified missing marker.

Complete code

def find_first(values, target):
    for index, value in enumerate(values):
        if value == target:
            return index
    return -1

print(find_first([8, 3, 7, 3], 3))
print(find_first([8, 3, 7, 3], 9))

Expected output

1
-1

Read it step by step

  1. enumerate supplies the zero-based index and its value.
  2. The first match returns immediately, so the later 3 is not returned.
  3. If the loop ends without a match, -1 is the chosen sentinel.
  4. Worst-case work grows linearly with the list length: O(n) time and O(1) extra space.

Remember: Document the missing marker so callers do not accidentally use -1 as a valid Python list index.

EXAMPLE 2 · PYTHON

Binary search: halve a sorted search range

Binary search needs sorted data. It compares with the middle and discards the half that cannot contain the target.

Complete code

def binary_search(values, target):
    low, high = 0, len(values) - 1
    while low <= high:
        mid = (low + high) // 2
        if values[mid] == target:
            return mid
        if values[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

print(binary_search([2, 4, 6, 8, 10], 8))
print(binary_search([], 8))

Expected output

3
-1

Read it step by step

  1. low and high bound the remaining inclusive range.
  2. Integer division // picks a valid middle index.
  3. The updates exclude the already-compared middle, ensuring progress.
  4. Time is O(log n) on a sorted random-access list; sorting an unsorted input first has its own cost.

Remember: Never apply this version to an unsorted list and trust the answer.

EXAMPLE 3 · PYTHON

Use a stack to check brackets

A stack remembers the most recent unmatched opening bracket. The next closing bracket must match it.

Complete code

def balanced(text):
    stack = []
    matching = {')': '(', ']': '[', '}': '{'}
    for char in text:
        if char in '([{':
            stack.append(char)
        elif char in matching:
            if not stack or stack.pop() != matching[char]:
                return False
    return not stack

print(balanced("([])"))
print(balanced("([)]"))

Expected output

True
False

Read it step by step

  1. append pushes an opening bracket onto the stack.
  2. pop removes the most recent opener, implementing last-in-first-out order.
  3. A closer with an empty stack or the wrong opener fails immediately.
  4. This checks bracket characters, not a full programming-language grammar; quoted strings are not specially parsed.

Remember: The stack structure mirrors nested matching. Time and worst-case space are O(n).

EXAMPLE 4 · PYTHON

Breadth-first search with a queue

BFS explores an unweighted graph in layers. A queue processes earlier discoveries before later ones.

Complete code

from collections import deque
graph = {"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}
queue = deque(["A"])
seen = {"A"}
order = []
while queue:
    node = queue.popleft()
    order.append(node)
    for neighbor in graph[node]:
        if neighbor not in seen:
            seen.add(neighbor)
            queue.append(neighbor)
print(order)

Expected output

['A', 'B', 'C', 'D']

Read it step by step

  1. deque supports removing the oldest queued item efficiently.
  2. Mark nodes seen when they are enqueued, preventing D from being added twice.
  3. Neighbor-list order determines the order among nodes at the same layer.
  4. With adjacency lists, work is O(V+E) for the explored graph; memory tracks the queue and visited nodes.

Remember: BFS finds shortest edge-count paths in unweighted graphs, not arbitrary weighted shortest paths.

EXAMPLE 5 · PYTHON

Merge two already-sorted lists

Keep a pointer into each list. Repeatedly take the smaller next value, then append any remaining tail.

Complete code

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i]); i += 1
        else:
            result.append(right[j]); j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

print(merge([1, 4, 7], [2, 4, 8]))

Expected output

[1, 2, 4, 4, 7, 8]

Read it step by step

  1. Each pointer identifies the next unused value.
  2. Choosing <= takes an equal value from the left first, preserving cross-list order for ties in a stable merge.
  3. Once either list ends, its partner’s remaining values are already ordered.
  4. Time is O(n+m); the returned list uses O(n+m) space.

Remember: This merges sorted inputs; it does not sort arbitrary unsorted inputs.

EXAMPLE 6 · PYTHON

Two-sum with remembered values

Remember earlier values so that each new value can ask whether its complement has appeared.

Complete code

def two_sum(values, target):
    seen = {}
    for index, value in enumerate(values):
        other = target - value
        if other in seen:
            return (seen[other], index)
        seen[value] = index
    return None

print(two_sum([2, 7, 11, 15], 9))
print(two_sum([3, 3], 6))

Expected output

(0, 1)
(0, 1)

Read it step by step

  1. For value 7 and target 9, the complement is 2.
  2. Check before inserting the current item, so it cannot pair with itself.
  3. Repeated values can still form a valid pair at different indices.
  4. Expected time is O(n) with ordinary hash-table behavior; extra storage is O(n).

Remember: Return indices or values deliberately: callers need to know which interpretation they receive.

EXAMPLE 7 · PYTHON

Dynamic programming: reuse earlier answers

The number of ways to climb n steps using steps of size 1 or 2 can be built from the two smaller answers.

Complete code

def ways(n):
    if n < 0:
        raise ValueError("n must be nonnegative")
    previous, current = 1, 1
    for _ in range(2, n + 1):
        previous, current = current, previous + current
    return current

print(ways(4))
print(ways(0))

Expected output

5
1

Read it step by step

  1. The final move is either one step from n−1 or two steps from n−2.
  2. The base case n=0 counts one empty sequence; n=1 has one way.
  3. Only the previous two counts are needed, so the code stores two integers.
  4. There are O(n) updates and O(1) stored integer objects; integer bit sizes grow with n.

Remember: A recurrence plus base cases makes repeated subproblems explicit.

EXAMPLE 8 · PYTHON

Prefix sums answer range questions quickly

Precompute totals before each position. A range total is the difference between two prefix totals.

Complete code

values = [3, 1, 4, 2]
prefix = [0]
for value in values:
    prefix.append(prefix[-1] + value)

def range_sum(start, stop):
    return prefix[stop] - prefix[start]

print(prefix)
print(range_sum(1, 3))

Expected output

[0, 3, 4, 8, 10]
5

Read it step by step

  1. prefix[k] holds the sum of values before index k.
  2. The query uses a half-open range: start is included and stop is excluded.
  3. For [1,3), subtract prefix[1]=3 from prefix[3]=8 to obtain 1+4=5.
  4. Building costs O(n) time and storage; each valid query costs O(1).

Remember: If the underlying values change, this stored prefix array must be updated or rebuilt.
