Start here: practice files & output conventions

Use Bash on Linux or a WSL Linux distribution on Windows. macOS includes several BSD tools with different flags. Each example starts independently in a fresh copy of the fixture below, with LC_ALL=C, ordinary Unix permissions and no default ACL. Do not run this setup inside an existing project.

Expected output is authored for this fixture. Illustrative output depends on your machine, network, interactive terminal or tool version; an excerpt may omit extra lines. A successful command can produce no output. The copy buttons copy commands only.
