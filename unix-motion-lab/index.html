A pipeline, one stage at a time.

Change the input and inspect how small text tools compose. This is a deterministic JavaScript simulation of these specific operations, not a general shell.

STREAM AT THIS STAGE
Stages: input → grep -F → LC_ALL=C sort → uniq → wc -l. Empty input is zero records; a trailing newline does not create an extra record. The simulation normalizes input lines to newline-terminated records. JavaScript ordering matches C-locale ordering for ASCII; Unicode collation is not modeled.
