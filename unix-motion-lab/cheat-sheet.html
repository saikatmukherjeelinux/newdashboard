Current directorypwdPrint the current directory. Paths beginning with / are absolute; other paths are relative.
Navigatecd ..; cd ~.. means parent directory; ~ means your home. cd is a shell built-in.
List filesls -lah-l: long listing; -a: include dotfiles; -h: human-readable sizes in long output.
Create directorymkdir -p practice/input-p creates missing parent directories and accepts an existing directory.
Copy and movecp -i source destination; mv -i old new-i asks before overwriting. cp copies; mv moves or renames. Use cp -R for directories.
Remove a filerm -i -- filename-i asks for confirmation; -- ends option parsing. Removal normally bypasses a desktop recycle bin.
Inspect texthead -n 5 file; tail -n 5 file-n 5 selects five lines. tail -f follows appended data; Ctrl+C stops it.
Find textgrep -n -F "error" file-n adds line numbers; -F treats the pattern literally. -i ignores case; -v keeps nonmatching lines.
Sortsort -n file-n compares numbers; -r reverses order; -u removes equal sorted lines.
Count duplicatessort file | uniq -cuniq groups adjacent equal lines; -c adds counts. Sorting brings equal lines together.
Count lineswc -l file-l counts newline characters; -w counts words; -c counts bytes (not necessarily characters).
Choose fieldscut -d, -f2 file-d sets a one-character delimiter; -f selects fields starting at 1. This is not a full CSV parser for quoted commas.
Replace textsed 's/old/new/g' files substitutes; g replaces every match on each line. Output goes to the terminal; the file is unchanged without in-place editing.
Calculate fieldsawk '{total += $2} END {print total}' file$2 is the second whitespace-separated field. END runs after the input is read.
Find pathsfind . -type f -name '*.txt'. is the search root; -type f selects regular files; -name matches the quoted filename pattern.
Permissionschmod u+x script.shu means owner; +x adds execute permission. Execution also depends on directory access and the script interpreter.
Streamscommand > out.txt; command >> out.txt> creates or truncates output; >> appends. 2> redirects errors. A pipe | connects standard output to the next command’s input.
Exit statuscommand; printf "%s\n" "$?"$? is the preceding command’s exit status: zero usually means success. grep uses 1 for no match and 2 for an error.
Processesps -ef; kill -TERM PIDps -e selects all processes; -f uses full format. TERM requests termination; substitute an actual PID you are authorized to stop.
Helpman grep; grep --helpman opens the manual (q quits). --help is common in GNU tools but is not universal.

Small examples with output

These examples are also explained step by step in the worked-example guide.

Print predictable lines with printf

Use a fixed set of fictional names as input. These examples target Bash with GNU/Linux utilities; they do not execute in the web page.

printf '%s\n' 'Ada' 'Ben' 'Cara'

Expected output

Ada
Ben
Cara

Prefer printf for predictable formatting; echo handling of escapes varies across environments.

Find matching lines and show their positions

A pipe sends one command’s output to the next command’s input. grep selects lines matching a pattern.

printf '%s\n' 'INFO ready' 'ERROR disk' 'ERROR network' | grep -n 'ERROR'

Expected output

2:ERROR disk
3:ERROR network

Line numbers refer to the input stream. grep normally returns status 1 when no line matches; that is not the same as a tool error.

Count repeated labels after sorting

uniq combines adjacent identical lines. Sorting first makes all identical labels adjacent.

export LC_ALL=C
printf '%s\n' 'red' 'blue' 'red' 'blue' 'red' | sort | uniq -c | awk '{print $1, $2}'

Expected output

2 blue
3 red

uniq alone only notices adjacent duplicates, so input ordering matters.

Sort numbers as numbers

Text sorting and numerical sorting answer different questions. Specify the intended interpretation.

printf '%s\n' 10 2 30 | sort -n

Expected output

2
10
30

GNU sort -n and -g have different numeric parsing rules. Use -g when you specifically need its general numeric format behavior.

Filter rows with awk and calculate a total

The fictional input has two whitespace-separated fields: a product name and a quantity.

printf '%s\n' 'pen 3' 'book 5' 'bag 2' | awk '$2 >= 3 {total += $2; print $1} END {print "total", total}'

Expected output

pen
book
total 8

The field format is part of the example. This is not a general CSV parser with quoted commas or embedded newlines.

Replace text using sed

sed can transform a stream without changing any existing file. This example replaces a word on every line.

printf '%s\n' 'red red' 'blue red' | sed 's/red/green/g'

Expected output

green green
blue green

sed patterns are regular expressions. Special characters need appropriate escaping when you intend literal matching.

Read the worked-example guide

Select a delimited field with cut

cut extracts positions or fields from simple delimited text.

printf '%s\n' 'Ada:10' 'Ben:20' | cut -d ':' -f 2

Expected output

10
20

For real CSV with quoting rules, use a CSV-aware parser rather than assuming cut handles every case.

Read the worked-example guide

Count a filtered result and inspect exit status

Commands communicate through both printed output and an exit status. They are different channels of information.

printf '%s\n' 'INFO ready' 'ERROR disk' 'ERROR network' | grep -c 'ERROR'
printf '%s\n' 'INFO ready' | grep -q 'ERROR'
status=$?
printf 'status=%s\n' "$status"

Expected output

2
status=1

These commands are for an ordinary interactive Bash session without set -e; automatic exit-on-failure scripts need deliberate handling of no-match results.
