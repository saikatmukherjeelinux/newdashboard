Quick reference

18 essential reminders
TopicSyntax or formulaMeaning and limitations
Feature and targetx = input; y = known answerA model predicts a target from features. Training uses known answers to adjust parameters.
Linear modelprediction = w·x + bw is a weight vector; x is a feature vector; b is the bias. For one feature, w·x is ordinary multiplication.
Dot product[1, 2] · [3, 4] = 1×3 + 2×4 = 11Multiply matching coordinates and sum them. Both vectors must have the same number of coordinates.
Matrix shapes(n × d) @ (d × k) → (n × k)The inner dimensions must agree. @ denotes matrix multiplication; * may mean elementwise multiplication.
Squared length||[3, 4]||² = 3² + 4² = 25The Euclidean length is the square root, 5. Length and squared length are different quantities.
Derivatived(x²)/dx = 2xA derivative measures local rate of change. At x=3, the slope is 6, not the function value 9.
Chain ruled f(g(x))/dx = f′(g(x)) × g′(x)Multiply local derivatives through a composition. Backpropagation applies this rule to model computations.
Gradient stepw_new = w_old - learning_rate × gradientMove against the gradient to reduce loss locally. A large learning rate can overshoot.
Mean squared errorMSE = sum((prediction - target)²) / nn is the number of examples. Larger errors receive more weight because of squaring.
Probability0 ≤ P(A) ≤ 1Probabilities for mutually exclusive, exhaustive outcomes sum to 1.
Conditional probabilityP(A|B) = P(A and B) / P(B)Restrict attention to cases where B holds; requires P(B)>0.
Bayes ruleP(A|B) = P(B|A)P(A) / P(B)Reverse a conditional probability using the base rate. P(A|B) and P(B|A) are not interchangeable.
Sigmoid1 / (1 + exp(-z))Maps a real score z to (0,1). A probability-like output is not automatically well calibrated.
Stable softmaxexp(z_i - m) / sum_j exp(z_j - m)m is the largest score. Subtracting it avoids overflow while preserving probabilities.
Standardizez = (x - training_mean) / training_SDFit scaling on training data only. Handle zero standard deviation explicitly.
Precision and recallprecision = TP/(TP+FP); recall = TP/(TP+FN)TP: true positives; FP: false positives; FN: false negatives. A zero denominator requires an explicit convention.
Regularizationobjective = data_loss + λ × penaltyλ controls the penalty strength. Choose it using validation data, not the held-out test set.
Data splitsTrain → validation → testTrain fits parameters, validation guides choices, and test estimates final held-out performance. Avoid information leakage.

Make a numeric prediction and inspect every contribution

A weighted sum is the same arithmetic as a shopping bill. Each feature contributes its value times its weight.

features = [2, 3]
weights = [4, -1]
contributions = [x * w for x, w in zip(features, weights)]
bias = 1
prediction = sum(contributions) + bias
print(contributions)
print(prediction)

Expected output

[8, -3]
6

A negative weight reduces a score; its meaning depends on the feature and fitted model.

Measure prediction error with MSE

Mean squared error turns a list of residuals into one nonnegative summary.

actual = [2, 4, 6]
predicted = [1, 5, 6]
errors = [p - y for p, y in zip(predicted, actual)]
squares = [e * e for e in errors]
print(errors)
print(squares)
print(f"MSE={sum(squares) / len(squares):.4f}")

Expected output

[-1, 1, 0]
[1, 1, 0]
MSE=0.6667

MSE emphasizes larger errors and uses squared target units. It is not the only sensible loss.

Follow gradient descent for three steps

This is a one-parameter training example with a known minimum at w=3.

w = 0.0
rate = 0.1
for step in range(1, 4):
    gradient = 2 * (w - 3)
    w -= rate * gradient
    loss = (w - 3) ** 2
    print(f"step={step} w={w:.4f} loss={loss:.4f}")

Expected output

step=1 w=0.6000 loss=5.7600
step=2 w=1.0800 loss=3.6864
step=3 w=1.4640 loss=2.3593

An optimization example is not evidence that every model will find a global minimum.

Calculate softmax without enormous exponentials

Softmax turns scores into positive values summing to one. Subtracting a shared maximum leaves the probabilities unchanged.

from math import exp
scores = [1000.0, 1001.0]
largest = max(scores)
scaled = [exp(x - largest) for x in scores]
total = sum(scaled)
probabilities = [x / total for x in scaled]
print([round(p, 4) for p in probabilities])
print(f"sum={sum(probabilities):.4f}")

Expected output

[0.2689, 0.7311]
sum=1.0000

A numerically stable formula can be algebraically equivalent to an unstable one.

Compute a Bayes update with counts

Fictional item flags illustrate why a useful detector can still produce many false alarms.

faulty_and_flagged = 8
good_and_flagged = 18
flagged = faulty_and_flagged + good_and_flagged
posterior = faulty_and_flagged / flagged
print(f"Flagged: {flagged}")
print(f"Faulty among flagged: {posterior:.2%}")

Expected output

Flagged: 26
Faulty among flagged: 30.77%

This is the probability of a fault given a flag, not the probability of a flag given a fault.

Build an attention-weighted mixture

Attention mixes value vectors using weights. This example supplies the weights so the mixing step is easy to inspect.

weights = [0.25, 0.75]
values = [[2, 0], [0, 4]]
result = [
    sum(weight * value[j] for weight, value in zip(weights, values))
    for j in range(2)
]
print(result)

Expected output

[0.5, 3.0]

The vector output keeps its coordinate dimension while combining information across positions.

Standardize using training information only

Preprocessing is part of the fitted procedure. Use the training mean and scale for later examples.

from statistics import mean, pstdev
train = [2, 4, 6]
center = mean(train)
scale = pstdev(train)
new_value = 8
z = (new_value - center) / scale
print(f"mean={center:.1f} scale={scale:.4f}")
print(f"new z={z:.4f}")

Expected output

mean=4.0 scale=1.6330
new z=2.4495

Including held-out data in fitted preprocessing can leak information into evaluation.

Check a tiny classifier beyond accuracy

Counts of true and false positives answer different questions from overall accuracy.

tp, fp, fn, tn = 30, 10, 20, 40
precision = tp / (tp + fp)
recall = tp / (tp + fn)
accuracy = (tp + tn) / (tp + fp + fn + tn)
print(f"precision={precision:.2f}")
print(f"recall={recall:.2f}")
print(f"accuracy={accuracy:.2f}")

Expected output

precision=0.75
recall=0.60
accuracy=0.70

Choose metrics that match the consequences of mistakes, not only the largest-looking score.
