# ML Lab — Mathematics for AI and machine learning

A standalone, buildless learning lab with 40 lessons, 80 worked examples, 40 practice questions with explained answers, 39 compact original SVG diagrams and three interactive experiments. Every lesson introduces the idea, defines its symbols, explains the steps, shows calculations and results, discusses a deeper connection and finishes with a mistake to avoid and a summary.

## Syllabus

1. Foundations: notation, algebra, functions, exponentials, logarithms, sets, logic and counting.
2. Linear algebra: vectors, tensor shapes, norms, dot products, projections, matrices, rank, least squares, eigenvalues, SVD and PCA.
3. Calculus: limits, derivatives, chain rule, partial derivatives, gradients, Jacobians, Hessians, Taylor approximations, integrals and changes of variables.
4. Probability: events, conditioning, independence, Bayes, moments, distributions, sampling, Monte Carlo and limit theorems.
5. Statistics: MLE, MAP, intervals, testing, bias and variance, evaluation, leakage, calibration and decision thresholds.
6. Information theory and numerics: entropy, cross-entropy, KL, mutual information, floating point and stable softmax.
7. Optimization: gradient descent, mini-batches, momentum, Adam, convexity, constraints and regularization.
8. Model mathematics: regression, classification, backpropagation, convolution, Fourier intuition and transformer attention.
9. Advanced connections: kernels, SVMs, clustering, mixtures, EM, graphs, Markov chains and reinforcement learning.
10. Generative mathematics: latent variables, variational inference, VAEs, diffusion and further study directions.

This is a broad core syllabus, not an exhaustive treatment of every mathematical research area. Advanced topics such as measure theory, stochastic calculus, causal inference, optimal transport and learning-theory bounds are signposted for further study.

## Use

Open `index.html`, or serve the dashboard root with `python -m http.server 4173` and open `/ml-motion-lab/`. No install, account, external fonts, CDNs or backend are needed. The syllabus, lesson links, search, module filters, bookmarks, progress, light/dark themes and experiments work locally. Progress uses the isolated browser-storage key `ml-math-lab-v1`; browser settings may prevent persistence.

Figures display at a maximum of 480 × 270 CSS pixels and shrink to the available width. Each has alternative text, a caption and a separate full-size link. All imagery is original SVG generated by `scripts/build-diagrams.py`, not copied from textbooks. Keyboard users can use the skip link, lesson links, native sliders and answer disclosures. The print action uses the browser print dialog.

## Content provenance

Teaching prose and numerical exercises are original and use fictional data. They contain no private-chat material, employer/client infrastructure, production logs or credentials. The Public references page links to publicly accessible textbooks and original papers for further study. Decimal approximations are labeled. No external dataset is loaded. Interactive plots describe their coordinate conventions; storyboard diagrams illustrate worked examples rather than measured data.

## Checks

- `node tests/content.cjs` checks lesson completeness, prerequisites, asset paths and independent numerical calculations.
- `node tests/browser.cjs` checks all lesson routes, image sizing, mobile layout, navigation, search, progress persistence, bookmarks, themes and the interactive calculations. It uses Playwright; set `ML_PLAYWRIGHT_PATH` to an existing Playwright package if it is not installed locally. Windows uses installed Edge.
- `python scripts/build-diagrams.py` regenerates SVG illustrations and their captions. Generated outputs are committed so Python is not needed to use the lab.

Browser screenshots are written to ignored `test-results/`. No JavaScript dependencies are needed to run the learning site.
