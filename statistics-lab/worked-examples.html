EXAMPLE 1 · PYTHON

Mean, median and two variance conventions

The standard library can calculate common summaries, but you still need to choose the correct interpretation.

Complete code

from statistics import mean, median, pvariance, variance
values = [2, 4, 6, 8]
print(f"mean={mean(values):.1f}")
print(f"median={median(values):.1f}")
print(f"population variance={pvariance(values):.4f}")
print(f"sample variance={variance(values):.4f}")

Expected output

mean=5.0
median=5.0
population variance=5.0000
sample variance=6.6667

Read it step by step

  1. The mean is 20/4=5. The median averages the middle pair 4 and 6.
  2. Squared distances from 5 are 9,1,1,9; their sum is 20.
  3. pvariance divides by 4, treating this list as the described population.
  4. variance divides by 3 for the usual sample-variance estimator. It requires at least two values.

Remember: Different denominator conventions answer different questions; neither should be chosen to manipulate a result.

EXAMPLE 2 · PYTHON

Build a frequency table with percentages

Count labels first, then divide by the explicitly defined sample size.

Complete code

from collections import Counter
answers = ["yes", "no", "yes", "yes", "no"]
counts = Counter(answers)
for label in sorted(counts):
    count = counts[label]
    print(f"{label}: {count} ({count / len(answers):.0%})")

Expected output

no: 2 (40%)
yes: 3 (60%)

Read it step by step

  1. Counter counts each occurrence of each label.
  2. The denominator is all five answers in this example.
  3. Sorting gives a predictable output order for comparison with the expected output.
  4. Missing or multiple-response answers would require an explicit denominator policy.

Remember: A percentage is meaningful only after its whole has been defined.

EXAMPLE 3 · PYTHON

Weighted averages for unequal groups

Combining group averages requires group sizes when the target is the overall observation-level mean.

Complete code

group_means = [10, 20]
group_sizes = [2, 8]
total = sum(m * n for m, n in zip(group_means, group_sizes))
combined = total / sum(group_sizes)
print(f"combined mean={combined:.1f}")
print(f"unweighted group mean={sum(group_means) / 2:.1f}")

Expected output

combined mean=18.0
unweighted group mean=15.0

Read it step by step

  1. A group’s mean times its size recovers its total.
  2. Combine totals 20 and 160, then divide by the 10 observations.
  3. The unweighted mean gives each group equal influence, despite different sizes.
  4. Both calculations can have a purpose, but they answer different questions.

Remember: Weight by observation count only when an individual-level combined mean is the target.

EXAMPLE 4 · PYTHON

Compute an exact binomial probability

This calculates one count probability directly for a small independent-trial model.

Complete code

from math import comb
n, k, p = 3, 2, 0.5
probability = comb(n, k) * p ** k * (1 - p) ** (n - k)
print(f"arrangements={comb(n, k)}")
print(f"probability={probability:.3f}")

Expected output

arrangements=3
probability=0.375

Read it step by step

  1. comb(3,2) counts which two trial positions are successes.
  2. p**k is the contribution from successes and (1-p)**(n-k) from failures.
  3. The combination factor includes all three successful arrangements.
  4. The model assumes fixed n, independent trials and the same p in each trial.

Remember: The formula gives a model probability, not a guarantee about a particular sample.

EXAMPLE 5 · PYTHON

Show the working in a normal-approximation interval

This example uses an explicitly supplied standard error and normal critical multiplier. It is not a universal small-sample recipe.

Complete code

estimate = 50.0
standard_error = 2.0
critical_value = 1.96
margin = critical_value * standard_error
print(f"margin={margin:.2f}")
print(f"interval=[{estimate - margin:.2f}, {estimate + margin:.2f}]")

Expected output

margin=3.92
interval=[46.08, 53.92]

Read it step by step

  1. A standard error describes uncertainty in the estimate, not spread of individual observations.
  2. Multiply by the critical value to obtain the margin.
  3. Subtract and add the margin to build the interval.
  4. Normal approximation and standard-error validity need justification; a t or design-based method may be appropriate instead.

Remember: The confidence interpretation belongs to the interval procedure and its assumptions.

EXAMPLE 6 · PYTHON

Analyze paired changes rather than unrelated groups

Before and after values must remain matched to the same units.

Complete code

from statistics import mean, stdev
from math import sqrt
before = [5, 7, 9, 10]
after = [6, 9, 12, 14]
differences = [b - a for a, b in zip(before, after)]
average = mean(differences)
se = stdev(differences) / sqrt(len(differences))
print(differences)
print(f"mean change={average:.4f}")
print(f"SE={se:.4f}")
print(f"t={average / se:.4f}")

Expected output

[1, 2, 3, 4]
mean change=2.5000
SE=0.6455
t=3.8730

Read it step by step

  1. Subtract before from after for each matched unit, yielding the differences.
  2. Calculate the mean and sample SD of differences, not two unrelated outcome SDs.
  3. Divide that SD by √number of pairs to get the SE under the independence assumptions.
  4. The statistic needs an appropriate t reference with 3 degrees of freedom for a p-value; this snippet stops at the statistic.

Remember: A paired analysis depends on valid matching and appropriate assumptions about the differences.

EXAMPLE 7 · PYTHON

Fit a small least-squares line

This hand-written calculation exposes the arithmetic of simple regression without an external package.

Complete code

from statistics import mean
x, y = [1, 2, 3], [2, 4, 5]
mx, my = mean(x), mean(y)
numerator = sum((a - mx) * (b - my) for a, b in zip(x, y))
denominator = sum((a - mx) ** 2 for a in x)
slope = numerator / denominator
intercept = my - slope * mx
print(f"slope={slope:.4f}")
print(f"intercept={intercept:.4f}")
print(f"prediction at 4={intercept + slope * 4:.4f}")

Expected output

slope=1.5000
intercept=0.6667
prediction at 4=6.6667

Read it step by step

  1. Center x and y around their own means.
  2. The slope is their centered cross-product sum divided by the centered x squared sum.
  3. Choose the intercept so the line passes through the two means.
  4. Prediction at 4 is beyond the observed x range 1–3, so it is an extrapolation that needs caution.

Remember: If every x were equal, the denominator would be zero and this slope would not be identifiable.

EXAMPLE 8 · PYTHON

Enumerate all bootstrap resamples of a tiny sample

For three observations there are only 3³=27 ordered same-size bootstrap samples, so exact enumeration is practical as a demonstration.

Complete code

from itertools import product
from statistics import mean
values = [2, 4, 6]
bootstrap_means = [mean(sample) for sample in product(values, repeat=3)]
print(f"resamples={len(bootstrap_means)}")
print(f"average of means={mean(bootstrap_means):.1f}")
print(f"range={min(bootstrap_means):.1f} to {max(bootstrap_means):.1f}")

Expected output

resamples=27
average of means=4.0
range=2.0 to 6.0

Read it step by step

  1. product with repeat=3 lists ordered draws with replacement, including repetitions such as (2,2,6).
  2. Each ordered resample has equal probability under this empirical sampling model.
  3. Compute a mean for every resample to examine a bootstrap distribution.
  4. The full minimum-to-maximum range is not a 95% confidence interval. Enumeration grows exponentially and is only for this tiny example.

Remember: Resampling reuses observed information; it does not create 27 new independent real-world studies.
