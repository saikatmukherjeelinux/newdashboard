Quick reference

20 essential reminders
TopicSyntax or formulaMeaning and limitations
Population and samplePopulation = target group; sample = observed subsetA large sample can still be biased if its collection method excludes relevant cases.
Meanmean = sum(x) / nn is the number of observations. The mean reacts to extreme values and retains the original measurement unit.
MedianSort; select the middle valueWith an even count, average the two middle values. The median is less sensitive to extreme values than the mean.
Weighted meansum(weight × value) / sum(weights)Weights must represent the intended contribution. The denominator must be nonzero.
Range and IQRrange = max - min; IQR = Q3 - Q1IQR spans the middle 50%. Software can use different sample quantile conventions.
VariancePopulation: sum((x-mean)²)/n; sample: divide by n-1Sample variance needs at least two observations. Variance has squared measurement units.
Standard deviationSD = sqrt(variance)Describes spread in the original units; it is not the uncertainty of the sample mean.
Standard errorSE(mean) ≈ sample_SD / sqrt(n)This usual estimate assumes independent observations with suitable finite variance. Dependence changes the calculation.
BinomialP(X=k) = C(n,k) p^k (1-p)^(n-k)n independent trials, each with the same success probability p; k counts successes.
PoissonP(X=k) = exp(-λ) λ^k / k!λ is the expected count in the interval. Check whether the event process assumptions fit the application.
Normal scoresz = (x - μ) / σμ is the population mean and σ its SD. A normal model needs justification; standardizing does not make data normal.
Confidence intervalestimate ± critical_value × SEThe method has repeated-sampling coverage. This is not generally a probability statement about a fixed parameter after observing the data.
Mean t intervalsample_mean ± t* × sample_SD / sqrt(n)t* uses n-1 degrees of freedom for the one-sample setting. Independence and distributional conditions matter.
p-valueP(result at least as extreme | null model)It is not the probability that the null is true, nor the chance that the result is important.
Paired comparisondifference_i = after_i - before_iAnalyze within-pair differences. Do not treat repeated measurements on the same unit as independent groups.
Correlation-1 ≤ Pearson r ≤ 1Measures linear association when defined. Zero does not rule out nonlinear dependence; association does not prove causation.
Regression residualresidual = observed - predictedInspect residual patterns and influential observations. Prediction intervals differ from confidence intervals for a mean response.
BootstrapResample observed units with replacementRespect the sampling structure: independent rows, clusters or time blocks as appropriate. Resampling cannot fix biased collection.
Multiple testsMore tests → more chances of false positivesChoose an appropriate family-wise or false-discovery control method; do not select only favorable results.
InterpretationEffect size + uncertainty + contextStatistical significance does not guarantee practical importance, representative sampling or a causal conclusion.

Mean, median and two variance conventions

The standard library can calculate common summaries, but you still need to choose the correct interpretation.

from statistics import mean, median, pvariance, variance
values = [2, 4, 6, 8]
print(f"mean={mean(values):.1f}")
print(f"median={median(values):.1f}")
print(f"population variance={pvariance(values):.4f}")
print(f"sample variance={variance(values):.4f}")

Expected output

mean=5.0
median=5.0
population variance=5.0000
sample variance=6.6667

Different denominator conventions answer different questions; neither should be chosen to manipulate a result.

Build a frequency table with percentages

Count labels first, then divide by the explicitly defined sample size.

from collections import Counter
answers = ["yes", "no", "yes", "yes", "no"]
counts = Counter(answers)
for label in sorted(counts):
    count = counts[label]
    print(f"{label}: {count} ({count / len(answers):.0%})")

Expected output

no: 2 (40%)
yes: 3 (60%)

A percentage is meaningful only after its whole has been defined.

Weighted averages for unequal groups

Combining group averages requires group sizes when the target is the overall observation-level mean.

group_means = [10, 20]
group_sizes = [2, 8]
total = sum(m * n for m, n in zip(group_means, group_sizes))
combined = total / sum(group_sizes)
print(f"combined mean={combined:.1f}")
print(f"unweighted group mean={sum(group_means) / 2:.1f}")

Expected output

combined mean=18.0
unweighted group mean=15.0

Weight by observation count only when an individual-level combined mean is the target.

Compute an exact binomial probability

This calculates one count probability directly for a small independent-trial model.

from math import comb
n, k, p = 3, 2, 0.5
probability = comb(n, k) * p ** k * (1 - p) ** (n - k)
print(f"arrangements={comb(n, k)}")
print(f"probability={probability:.3f}")

Expected output

arrangements=3
probability=0.375

The formula gives a model probability, not a guarantee about a particular sample.

Show the working in a normal-approximation interval

This example uses an explicitly supplied standard error and normal critical multiplier. It is not a universal small-sample recipe.

estimate = 50.0
standard_error = 2.0
critical_value = 1.96
margin = critical_value * standard_error
print(f"margin={margin:.2f}")
print(f"interval=[{estimate - margin:.2f}, {estimate + margin:.2f}]")

Expected output

margin=3.92
interval=[46.08, 53.92]

The confidence interpretation belongs to the interval procedure and its assumptions.

Analyze paired changes rather than unrelated groups

Before and after values must remain matched to the same units.

from statistics import mean, stdev
from math import sqrt
before = [5, 7, 9, 10]
after = [6, 9, 12, 14]
differences = [b - a for a, b in zip(before, after)]
average = mean(differences)
se = stdev(differences) / sqrt(len(differences))
print(differences)
print(f"mean change={average:.4f}")
print(f"SE={se:.4f}")
print(f"t={average / se:.4f}")

Expected output

[1, 2, 3, 4]
mean change=2.5000
SE=0.6455
t=3.8730

A paired analysis depends on valid matching and appropriate assumptions about the differences.

Fit a small least-squares line

This hand-written calculation exposes the arithmetic of simple regression without an external package.

from statistics import mean
x, y = [1, 2, 3], [2, 4, 5]
mx, my = mean(x), mean(y)
numerator = sum((a - mx) * (b - my) for a, b in zip(x, y))
denominator = sum((a - mx) ** 2 for a in x)
slope = numerator / denominator
intercept = my - slope * mx
print(f"slope={slope:.4f}")
print(f"intercept={intercept:.4f}")
print(f"prediction at 4={intercept + slope * 4:.4f}")

Expected output

slope=1.5000
intercept=0.6667
prediction at 4=6.6667

If every x were equal, the denominator would be zero and this slope would not be identifiable.

Enumerate all bootstrap resamples of a tiny sample

For three observations there are only 3³=27 ordered same-size bootstrap samples, so exact enumeration is practical as a demonstration.

from itertools import product
from statistics import mean
values = [2, 4, 6]
bootstrap_means = [mean(sample) for sample in product(values, repeat=3)]
print(f"resamples={len(bootstrap_means)}")
print(f"average of means={mean(bootstrap_means):.1f}")
print(f"range={min(bootstrap_means):.1f} to {max(bootstrap_means):.1f}")

Expected output

resamples=27
average of means=4.0
range=2.0 to 6.0

Resampling reuses observed information; it does not create 27 new independent real-world studies.
